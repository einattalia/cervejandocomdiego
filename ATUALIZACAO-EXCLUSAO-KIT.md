# Exclusão de kits

O editor de kits agora mostra a opção **Excluir kit** para kits existentes. A ação pede confirmação, apaga o kit e seus componentes associados, e preserva os dados históricos dos pedidos. A opção **Desativar kit** continua disponível para apenas removê-lo do catálogo sem apagá-lo. Componentes individuais podem ser removidos pelo botão **Remover** na lista de componentes.
